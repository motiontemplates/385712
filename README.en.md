## Start

This is ordinary public source with no Key; local creation requires no login. Download the [English MotionGit .motion template](https://motiontemplates.github.io/385712/downloads/kinetic-tech-en.motion), extract into a new folder, and read PUBLIC-SOURCE.md, guide.en.json and the parameter contract. Use the included kinetic_bootstrap.py source workflow (doctor → capabilities → plan → prepare → preview → render), resolve only missing declared dependencies, and show real previews made with your content. Preserve old packages, projects and caption clocks.

The [official personal package](https://motiongit.com/@adunext/385712) is the main entry for API services and signed incremental updates. Use its verified bundled assistant and original Key, saving new packages separately; do not copy or request a Key. The public local workflow does not require a personal package.
