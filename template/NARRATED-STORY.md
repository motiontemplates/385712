# Narrated story production / 随口播制作

New narration with real captions and optional photos/videos: use the normal `compose --input <current-user.json> --out <fresh-user-ready.json>` entry, then plan/prepare/preview/render the returned input. Compose sets `creationProfile:"narrated-story/1"`, `narrationVisualMode:"follow-speech"` and `narrationLayout:"balanced"` unless explicitly selected. It computes caption references from the real complete cues, without editing the captions, original audio or evidence. Existing inputs and instances retain their original mode. The simple compose route selects existing B1–B4; other native groups retain their existing entry and semantic contracts.

Give each scene its current title/basic content and optional `captionTargets:{"0":"explanation","1":["left","right"]}`. Keys are actual zero-based caption indices, values are real visible fields. A whole comparison sentence may show both sides together. Sentence text and timestamps remain complete when a visual shot cuts through it; those repeated plan references are context, never duplicated audio/subtitles or invented word times. Genuine word accents still require the existing real alignment evidence. The scene's basic duration remains 8/10/10/8 seconds plus its allowed reading hold, preserving native speed.

When actual word evidence is supplied, optional `phraseTargets:[{captionIndex:0,text:"Actual spoken phrase",target:"points.0"}]` finds a unique exact phrase in the unchanged measured word records. Compose fills its actual first/last times and contiguous wordIndices, then the original evidence validator checks the file hash, bound source identity and words again. Missing/ambiguous phrases fail; sentence-only data never becomes a word clock. Every B2 point needs a real cue or phrase target. With one point per cue, compose can map their supplied order; it does not infer semantic truth. New projects trigger existing basic point/comparison/action entrances and their original sound samples at the measured onset, keeping the animation duration and old-project behavior.

For narration plus media, use `presenter.mode:"none"` and optional `scenes[].visuals:[{captionIndex:0,mode:"image",file:"photo.jpg",fit:"contain",label:"Actual supplied photo"}]`. Video mode additionally accepts an actual `sourceStart` offset. A visual appears at that cue's real start (or the shot start when it continues an earlier cue), stays until the next visual/shot end, and plays at normal speed. It must cover that range; no implicit loop, speed change or invented frames. Images can use contain or an explicitly chosen cover crop. Video sound is not the narration track: preserve narration with the explicit voice/presenter binding. This media-led layout currently supports B1–B4 without a presenter, Chinese/English landscape/portrait. It uses original fonts, glass/metal colors, the existing captions, HUD, signature and separately mixed sound effects. Without visuals, existing basic/native rendering stays in place.

Every sentence must have a real visible target. The composed default uses the scene's explanation/heading/action; adjust captionTargets to actual points/comparison sides when meaning changes. A repeated heading is only a draft, not semantic acceptance. Review `narrationAlignment.visualCoverage` and actual frames. `mediaUsage` reports every scene visual's output interval and unused global roles. Set `requiredMediaRoles` for any supplied global roles which must be used; an unused required role is an error. Other unused inputs produce actionable warnings. This avoids silently ignoring supplied media without forcing irrelevant images into a film.
