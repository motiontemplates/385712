## 开始制作

本仓库提供无 Key 的普通公开源码，可免登录本地制作。下载[中文 MotionGit .motion 模板](https://motiontemplates.github.io/385712/downloads/kinetic-tech-zh.motion)，解压到新目录，先读 PUBLIC-SOURCE.md、guide.json 和参数合同。使用包内 kinetic_bootstrap.py 普通入口（doctor → capabilities → plan → prepare → preview → render），只补实际缺少的声明依赖，用你的内容制作并展示真实预览；保留旧包、工程与原始字幕。

[官网个人包](https://motiongit.com/@adunext/385712)是 API 服务与签名增量更新的主入口，按其已验证的随包助手沿用本人原 Key 更新并另存新包；不要复制或索要 Key。公开源码本地制作不需要先取得个人包。
